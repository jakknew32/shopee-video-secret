# 🎬 Affilimate AI Video Studio (แอฟฟิลิเอต ชอร์ต วิดีโอ สตูดิโอ)

เว็บแอปพลิเคชันสร้างคลิปสั้น **TikTok, Instagram Reels, และ YouTube Shorts** (อัตราส่วนแนวตั้ง 9:16) สำหรับทำ **Affiliate Marketing** โดยเฉพาะ รองรับการเชื่อมต่อกับโมเดล AI ชั้นนำระดับโลก:
- 🌟 **Google Flow (Gemini 1.5/2.0 Flash/Pro)**
- 🚀 **Grok (xAI Grok-2 / Grok-Beta)**
- 🟣 **Meta AI (Llama 3.3 / Llama 3.1)**
- ⚡ **Smart Auto Optimizer** (ระบบ AI จำลองอัจฉริยะ ใช้งานได้ทันที 100% แม้ไม่มี API Key)

---

## 🚀 จุดเด่น & ฟังก์ชันใหม่ล่าสุด

### 1. 🧡 ระบบดึงรูป & ข้อมูลสินค้าจาก Shopee (Shopee Auto-Extractor)
- **วางลิงก์ Shopee หรือข้อความแชร์**: รองรับทั้ง `https://shopee.co.th/...` และ Short Link `https://s.shopee.co.th/...`
- **ดึงคลังรูปภาพสินค้าความละเอียดสูง**: ดึงภาพสินค้าหลายมุม และนำไปจัดใส่ทั้ง 5 ฉาก (Hook → Pain Point → Reveal → Proof → CTA) ให้โดยอัตโนมัติ
- **ดึงสเปกและรีวิวสินค้า**: ดึงราคาจริง, ราคาเต็ม, ส่วนลด %, คะแนนดาวรีวิว และยอดขาย มาช่วยคำนวณสคริปต์ที่น่าเชื่อถือ
- **มีคลังสินค้าฮิตในตัว**: สามารถคลิกเลือกตัวอย่างสินค้าขายดี (หูฟัง ANC, หม้อทอดไร้น้ำมัน, เซรั่มไฮยา, แก้วเก็บความเย็น 304, ไมค์ไร้สาย) เพื่อทดลองดึงรูปและประกอบคลิปได้ทันที

### 2. ⚙️ ตัวเลือกปรับแต่ง AI Prompt & Persona แบบละเอียด (Custom Prompt System)
- **สูตรโครงสร้าง Prompt พิเศษ**:
  - `🔄 Before & After`: เปรียบเทียบสภาพก่อนใช้ vs หลังใช้ชัดเจน
  - `⚖️ Pros & Cons`: รีวิวเจาะลึกข้อดี vs ข้อควรระวัง (เพิ่มความน่าเชื่อถือ)
  - `💎 Hidden Gem`: ไอเทมลับนอกกระแสที่คนส่วนใหญ่ยังไม่รู้
  - `🔥 Payday / Flash Sale`: เน้นความเร่งรีบ สต็อกจำกัด โค้ดลดพิเศษ
  - `📦 Sensory Unboxing`: แกะกล่องสัมผัสความพรีเมียม
- **สวมบทบาทครีเอเตอร์ (AI Persona)**:
  - ครีเอเตอร์สายแกดเจ็ต / เทคโนโลยี
  - บิวตี้บล็อกเกอร์ / ตัวแม่ป้ายยา
  - แม่ค้าไลฟ์สดพลังบวก (Live Streamer)
  - เพื่อนสนิทบอกเพื่อน (Real Friend)
  - แม่บ้าน / พ่อบ้านยุคใหม่นักคำนวณ
- **คำสั่งเฉพาะเจาะจง (Custom Instructions)**: สั่งให้ AI ใช้สำนวนเฉพาะ เช่น *"เน้นภาษาวัยรุ่น Gen Z"*, *"เน้นย้ำเรื่องรับประกัน 2 ปี"*
- **ข้อห้ามเด็ดขาด (Negative Constraints)**: เช่น *"ห้ามใช้คำว่า ซื้อเลย"*, *"ห้ามเคลมเกินจริง"* เพื่อป้องกันคลิปโดนปิดกั้นการมองเห็น (Shadowban)
- **Live Raw Prompt Preview**: ดูและคัดลอกคำสั่ง Prompt ดิบที่ส่งไปยัง Gemini / Grok / Meta AI ได้แบบ Real-time

### 3. 📱 9:16 Vertical Video Studio (Google Chrome Canvas Engine)
- **Smartphone Live Mockup**: กรอบมือถือพร้อมระบบจำลอง TikTok UI (ปุ่ม Like, Comment, ตะกร้าสินค้า, แผ่นเสียงหมุน)
- **Kinetic TikTok Subtitles**: ซับไตเติลภาษาไทยสวยงาม พร้อมไฮไลต์คำกระตุ้นอารมณ์สีเหลืองทอง (เช่น *"พลาดมาก"*, *"เจอตัวจบแล้ว"*, *"กดตะกร้าซ้ายล่าง"*)
- **Ken Burns Motion**: ซูมเข้า (Zoom In), ซูมออก (Zoom Out), เลื่อนกล้อง (Pan Up/Down), เต้นตามจังหวะ (Pulse)
- **Affiliate Badges & Stickers**: ตะกร้าเหลือง TikTok, ป้าย Flash Sale, ป้ายลด 50%, ป้ายรีวิว 5 ดาว, ป้ายส่งฟรี, ป้าย Shopee Deal

### 4. 🗣️ Web Speech TTS & BGM Sound Synthesizer
- **เสียงพากย์ภาษาไทยบน Google Chrome**: ตรวจจับเสียงพากย์ไทยในเครื่อง พร้อมปรับสปีด (แนะนำ 1.15x สไตล์ TikTok)
- **Sound Effects (SFX)**: เสียงฟิ้วว (Woosh), ปิ๊งง (Ding), ชะชิ้งกริ๊งๆ (Cash Register), ป๊อป (Pop), ชัตเตอร์กล้อง (Camera Snap)
- **BGM Synthesizer**: เพลงประกอบสร้างจาก Web Audio API พร้อมระบบ **Auto-Ducking** ลดเสียงเพลงอัตโนมัติเมื่อมีเสียงพากย์

### 5. 📥 Video Render & 1-Click Export
- **เรนเดอร์วิดีโอ 9:16**: บันทึกภาพแอนิเมชันและเสียงรวมเป็นไฟล์วิดีโอ (.webm / .mp4 HD) ดาวน์โหลดได้ทันที
- **Copywriter Assistant**: 1-Click คัดลอกแคปชั่นป้ายยา, แฮชแท็กไวรัล และสคริปต์คำพูด

## 🛠️ วิธีการเปิดใช้งานบน Google Chrome

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์รัน
ดับเบิ้ลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์นี้ ระบบจะเปิด Google Chrome ให้อัตโนมัติที่ `http://localhost:3000`

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
```bash
npm run dev
```
จากนั้นเปิด Google Chrome แล้วเข้าไปที่ `http://localhost:3000`

## 🔑 การตั้งค่า API Keys (ไม่บังคับ)

1. คลิกที่ปุ่ม **"API Keys"** บนแถบเมนูด้านบน
2. เลือกใส่ API Key ตามที่ต้องการ:
   - **Google Flow (Gemini)**: ขอคีย์ฟรีได้ที่ [Google AI Studio](https://aistudio.google.com/app/apikey)
   - **Grok (xAI)**: ขอคีย์ได้ที่ [xAI Console](https://console.x.ai)
   - **Meta AI (Llama 3)**: ขอคีย์ฟรีได้ที่ [Groq Cloud](https://console.groq.com/keys)
3. กด **"บันทึกการตั้งค่า"** (คีย์จะถูกบันทึกไว้ใน LocalStorage ในเครื่องของคุณอย่างปลอดภัย 100%)
